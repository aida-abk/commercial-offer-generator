# JT Electrics — Генератор коммерческих предложений

Веб-приложение для автоматического формирования КП по PDF проектам электрики и дизайна.

## Возможности

- Загрузка PDF проекта (план электрики, РОЗЕТКИ/СВЕТ/ВЫКЛ)
- AI извлечение объёмов (розетки, выключатели, свет, UTP, площадь)
- Автоматический расчёт материалов и щита по каталогу JT Electrics
- Ручная правка сметы перед выгрузкой
- Генерация PDF в фирменном формате КП
- Админка цен материалов

## Быстрый старт

```bash
npm install
npx prisma db push
cp .env.example .env   # задайте OPENAI_API_KEY и APP_PASSWORD
npm run dev
```

Откройте http://localhost:3000 — пароль по умолчанию: `jt-electrics`

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `OPENAI_API_KEY` | Ключ OpenAI для vision-извлечения из PDF |
| `APP_PASSWORD` | Пароль входа в приложение |
| `DATABASE_URL` | SQLite: `file:./dev.db` |

## Ручной ввод

Если API-ключ не задан, используйте форму «Ввести данные вручную» на главной странице.

## Проверка калькулятора

```bash
npx tsx scripts/validate-calculator.ts
```

## Структура

- `config/price-catalog.json` — цены материалов и щита
- `config/calculation-rules.json` — формулы расчёта количеств
- `config/company-boilerplate.json` — текст КП (гарантии, контакты)
- `Примеры КП/` — эталонные PDF для калибровки
