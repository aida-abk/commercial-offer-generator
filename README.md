# JT Electrics — Генератор коммерческих предложений

Веб-приложение для автоматического формирования КП по PDF проектам электрики и дизайна.

## Возможности

- Загрузка PDF дизайн-проекта (план электрики, РОЗЕТКИ/СВЕТ/ВЫКЛ)
- AI извлечение **покомнатного** состава: розетки, точки света, выключатели,
  тёплый пол, кондиционеры, UTP по каждому помещению
- Таблица помещений правится руками перед расчётом
- Автоматический расчёт групп, кабеля, материалов и щита по каталогу JT Electrics
- Ручная правка сметы перед выгрузкой
- История КП: сохраняется автоматически, можно открыть, пересчитать или удалить
- Генерация PDF в фирменном формате КП
- Админка цен материалов

## Быстрый старт

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `OPENAI_API_KEY` | Ключ OpenAI для vision-извлечения из PDF |
| `OPENAI_VISION_MODEL` | Модель распознавания (по умолчанию `gpt-4o`) |
| `OPENAI_PAGES_PER_REQUEST` | Листов в одном запросе (по умолчанию 3). Уменьшите, если аккаунт упирается в лимит токенов в минуту |
| `OPENAI_TPM_BUDGET` | Лимит токенов в минуту у аккаунта (по умолчанию 9000). Поднимите вместе с тарифом, тогда разбор пойдёт без пауз |
| `APP_PASSWORD` | Пароль входа в приложение |
| `DATABASE_URL` | SQLite: `file:./dev.db`, на сервере `file:/data/offers.db` |
| `DATA_DIR` | Папка изменяемых данных на сервере (прайс). Локально не нужна |

## Как читается PDF

1. `src/lib/pdf-page-analyzer.ts` — по тексту страниц выбирает нужные листы
   (план электрики, розетки, свет, выключатели, тёплый пол, экспликация).
   Если текстового слоя нет (чертёж в кривых), берутся первые 8 страниц.
2. `src/lib/pdf-to-images.ts` — рендерит выбранные листы в PNG **через Chrome**
   (pdf.js исполняется на странице). Нативные canvas-биндинги в Node с pdf.js 4
   не работают: node-canvas падает на встроенных картинках, `@napi-rs/canvas`
   роняет процесс.
3. `src/lib/vision-extract.ts` — отправляет листы пачками (лимит токенов в минуту),
   отдельно передавая текст страниц: экспликация читается текстом, точки — по
   изображениям. Сбойная пачка не валит разбор, а попадает в заметки.

## Сколько стоит распознавание

OpenAI используется только в одном месте — разбор PDF (`src/lib/vision-extract.ts`).
Генерация КП, расчёт и PDF на выходе работают локально и ничего не стоят.

Расход виден после каждого разбора: строка «Распознавание: N токенов ≈ $X» на шаге
подтверждения, и в консоли через `npm run debug:extract "<PDF>"`.

Основная статья — картинки листов: один лист A3 в режиме high detail ≈ 2 000–2 500
токенов. Пачки по `OPENAI_PAGES_PER_REQUEST` листов повторяют системный промпт,
поэтому чем меньше пачка, тем больше накладные расходы. Цены gpt-4o заданы в
`usageCostUsd` — если тариф изменится, правьте там.

## Модель расчёта

Смета считается не от общих цифр, а от **групп по помещениям** (`src/lib/circuits.ts`):

| Что | Правило |
|-----|---------|
| Освещение | одна комната — один автомат 10А, кабель ВВГнг 3*1,5 |
| Розетки | одна комната — один автомат 16А, кабель ВВГнг 3*2,5, без шлейфа, через распредкоробки |
| Кухня | всегда 4 группы: варочная (ВВГнг 3*6, 32А), холодильник, духовой шкаф + СВЧ, прочие розетки |
| Отдельные группы | каждый кондиционер (до внутреннего блока), каждый контур тёплого пола, «Нептун» |
| Софиты | внутри группы идут шлейфом софит-софит (ВВГнг 2*1,5) |
| Проходные | коридор и спальня (у входа и у изголовья), реже из 3 мест |
| Трасса | кабель по потолку от щита + спуск по стене 3 м на каждую точку |
| Запас | 4% на срезы |
| УЗО | 3–4 розеточные группы 16А на один аппарат |
| Корпус щита | модули по факту + 12 в запас (ввод 2п 63А — 2 модуля, реле напряжения — 2, контактор — 2, УЗО — 2, автомат 1п — 1, колодка РБД — 1,5) |
| Лампочки | временное освещение 3–4 на комнату |
| Площадь | общая, включая балконы, санузлы и тех.помещения |
| Работы | 7000 ₸/м² по умолчанию |

Если помещения не распознаны (старое КП или ручной ввод), состав восстанавливается
по площади — `src/lib/rooms.ts` → `synthesizeRooms`, и его видно в таблице на шаге
подтверждения.

## Проверка калькулятора

```bash
npm run validate     # проверка правил на контрольной квартире
npm run benchmark    # сравнение с эталонными КП из «Примеры КП»
npm run calibrate    # подбор геометрии трасс по эталонным КП
npm run debug:plan   # группы и кабель по одному объекту
npm run debug:panels # состав щита по всем эталонным объектам
npm run debug:extract "Примеры КП/РП Aididar 90м2 interior design.pdf"  # что распознано из PDF
```

Бенчмарк сравнивает материалы и щит при **исторической** цене работ из самого КП:
ставка за работы изменилась, и без этого она маскировала бы расхождения.

## Структура

- `config/price-catalog.json` — цены материалов и щита
- `config/calculation-rules.json` — геометрия трасс, ширина модулей, формулы расходников
- `src/lib/circuits.ts` — сборка групп по комнатам и длины кабеля
- `src/lib/rooms.ts` — типы помещений и восстановление состава по площади
- `config/company-boilerplate.json` — текст КП (гарантии, контакты)
- `Примеры КП/` — эталонные PDF для калибровки
